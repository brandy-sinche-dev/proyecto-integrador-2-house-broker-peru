# Diseño UX/UI del Chatbot y Módulo de Recomendaciones

## Objetivo

Se diseñó la experiencia UX/UI del módulo **Concierge AI** de House Broker Perú, orientado a brindar asistencia personalizada durante la búsqueda de propiedades y presentar recomendaciones de acuerdo con las preferencias del usuario.

## Chatbot Concierge AI

Se diseñó una interfaz conversacional que permite al usuario interactuar con el asistente de House Broker Perú mediante mensajes y opciones rápidas.

El chatbot incluye:

- Mensaje de bienvenida personalizado.
- Campo para ingresar consultas inmobiliarias.
- Opciones rápidas de búsqueda.
- Indicador de estado del asistente.
- Respuestas personalizadas según la consulta.
- Acceso a propiedades recomendadas.
- Acciones para ver el detalle y agendar una visita.

## Flujo de interacción

Se diseñó el flujo principal de interacción:

- Inicio de conversación con Concierge AI.
- Identificación de la zona o características de interés.
- Ingreso de preferencias.
- Procesamiento de la solicitud.
- Presentación de propiedades recomendadas.
- Visualización del detalle de una propiedad.
- Agendamiento de una visita VIP.

## Recomendaciones de Propiedades

Las propiedades recomendadas se muestran dentro del flujo de conversación.

La recomendación presenta:

- Porcentaje de coincidencia AI.
- Ubicación.
- Tipo de propiedad.
- Precio.
- Precio aproximado por m².
- Área.
- Dormitorios.
- Baños.
- Cocheras.
- Características destacadas.
- Botón para ver el detalle.
- Botón para agendar una visita VIP.

## Match AI

Se incorporó un indicador visual de **Match AI** para comunicar el nivel de coincidencia entre las preferencias del usuario y una propiedad.

Ejemplo mostrado en el prototipo:

- **98% MATCH AI**
- Av. Pezet, San Isidro.
- Penthouse Dúplex con Vista al Golf.
- Terraza panorámica.
- Acabados de lujo.

## Preferencias de Búsqueda

Se diseñó una interfaz para definir criterios antes de recibir recomendaciones.

Se consideran:

- Tipo de propiedad.
- Rango de presupuesto.
- Amenidades clave.
- Piscina.
- Gimnasio.
- Cochera.
- Seguridad.

## Criterios de aceptación

El prototipo de Figma incluye:

- Flujo de conversación con Concierge AI.
- Ingreso de consultas del usuario.
- Respuestas del asistente.
- Opciones rápidas de búsqueda.
- Presentación de propiedades recomendadas.
- Indicador de porcentaje de coincidencia AI.
- Visualización del detalle de la propiedad.
- Acciones para agendar una visita VIP.
