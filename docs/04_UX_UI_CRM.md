# Diseño UX/UI del CRM y Agendamiento de Citas

## Task

TASK-UI-CRM-01

## Objetivo

Diseñar la interfaz de usuario para el seguimiento de leads comerciales
y la gestión de agenda de visitas.

## Diseños realizados

### Pipeline Kanban de Leads

Se diseñó un tablero Kanban para gestionar los leads mediante los estados:

- NUEVO
- CONTACTADO
- VISITA_AGENDADA
- GANADO
- PERDIDO

### Ficha de Detalle de Cliente

Se diseñó la ficha del cliente mostrando su información e historial de interacciones.

### Calendario de Agenda del Agente

Se diseñó el calendario para gestionar las citas del agente mediante:

- Vista diaria
- Vista semanal

### Selector de horarios

Se diseñó un selector interactivo para que el cliente pueda consultar y seleccionar horarios disponibles para una cita.

## Criterios de aceptación

El prototipo de Figma incluye:

- Flujo de cambio de estado de leads.
- Flujo de reserva de citas.
- Navegación entre las pantallas principales.
