# Diseño UX/UI de Autenticación

## Task
TASK-UI-SEC-01

## Objetivo
Diseñar las pantallas de acceso y seguridad del sistema House Broker Perú.

## Diseños realizados

### Login
Pantalla de inicio de sesión para los usuarios del sistema.

### Recuperación de contraseña
Pantalla para recuperar el acceso mediante correo electrónico.

### Vistas por rol
Se diseñaron vistas adaptadas a los siguientes roles:

- CLIENTE
- AGENTE
- ADMIN

Los componentes visibles cambian según el rol del usuario.

### Plantillas de correo

Se diseñaron las siguientes plantillas:

- Confirmación de cita.
- Recordatorio de cita.
