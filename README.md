# House Broker Peru

Plataforma web de intermediación inmobiliaria desarrollada como **Proyecto Integrador II** en la universidad. Permite conectar propietarios, compradores e intermediarios inmobiliarios en un solo entorno digital.

## Estructura del proyecto

```
├── backend/          # API y lógica del servidor (Django)
├── frontend/         # Interfaz de usuario (React + TypeScript + Vite)
├── docs/             # Documentación: planificación, requerimientos, arquitectura, UX/UI, etc.
├── infra/            # Infraestructura y configuración de Docker
├── Laboratorios/     # Laboratorios realizados en clase (asignaciones del profesor)
├── Secciones/        # Contenido de las sesiones de clase
```

## Laboratorios y Secciones

- **Laboratorios/**: Son trabajos prácticos asignados por el profesor durante las clases. Cada laboratorio contiene su documentación y evidencias de la práctica realizada.
- **Secciones/**: Contiene los materiales y resultados de las sesiones de clase impartidas por el profesor.
